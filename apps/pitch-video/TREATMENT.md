# LingXi 90 秒企业 SaaS 路演视频

## 创意命题

**同一个问题，为什么答案总是不一样？因为答案，本就不该一样。**

影片不从功能清单开始，而是从传统 AI 学习产品“答案相同、路径固定”的矛盾切入。LingXi 的差异化答案是：以学习状态为核心，让 Skill 动态组合，让每一次学习证据改变下一步。

## 视觉与声音

- 画面：1920×1080，30fps，90 秒。
- 色彩：石墨黑为主，荧光青、淡紫、酸性绿和珊瑚橙分别映射理解、图解、练习和反馈。
- 字体：品牌自带 Geist 与 Season Sans；中文回退至系统苹方。
- 剪辑：章节式硬朗转场，镜头运动克制，数据证据段落达到视觉高潮。
- 声音：Reed 中文男声分镜录制，每幕入点独立控制，避免旁白抢在转场之前；后续音乐必须使用具有商业授权的低频企业科技氛围素材。
- 联系方式：`https://lingxilearn.cn`、`team@lingxilearn.cn`、`github.com/LingXi-Org/LingxiLearn`。

## 审片标准

1. 关掉声音后，仍能只看画面和字幕理解产品。
2. 不使用未经确认的营收、留存或学习效果数据。
3. “200+ 人次”明确表述为累计服务人次，不暗示独立用户数。
4. 产品 UI 只展示仓库中的真实界面，不绘制虚假功能截图。
