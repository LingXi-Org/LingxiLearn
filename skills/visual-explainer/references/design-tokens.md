# 设计令牌与配色

页面的全部颜色、字体、间距都从 `assets/lingxi.css` 的令牌里取。**不要在页面里写死颜色**，唯一例外见文末「物理写实场景」。

## 一、学术论文风的五条硬规则

1. **衬线标题、无衬线正文、等宽数字。** 标题走 `--font-serif`，正文走 `--font-sans`，任何会变化的数值走 `--font-mono` + `font-variant-numeric: tabular-nums`（不加这条，滑块拖动时数字会左右抖）。
2. **只用 400 与 500 两档字重。** 600/700 在米白纸面上显脏。强调靠字号与颜色层级，不靠加粗。
3. **平面。** 无渐变、无阴影、无发光、无模糊。唯一允许的 `box-shadow` 是 `:focus-visible` 的焦点环。
4. **发丝线。** 所有分隔线、图形描边一律 `0.5px`（`--hairline`）。2px 只留给「当前选中」这一种状态。
5. **图必有号有注。** 每张图放进 `<figure>`，配 `<figcaption>`；编号由 CSS counter 自动生成（「图 1 ·」）。图注写的是**这张图说明了什么**，不是重复标题。

## 二、界面令牌

| 用途 | 令牌 | 亮色 | 暗色 |
|---|---|---|---|
| 页面纸面 | `--paper` | `#fbfaf7` | `#1a1a19` |
| 卡片面 | `--surface` | `#ffffff` | `#232322` |
| 凹陷面（控件区、KPI） | `--sunken` | `#f4f2ec` | `#2c2c2a` |
| 正文墨色 | `--ink-1` | `#23231f` | `#edebe4` |
| 次级文字 | `--ink-2` | `#5f5e5a` | `#b4b2a9` |
| 提示文字 | `--ink-3` | `#8a8880` | `#888780` |
| 分隔线 | `--rule` / `--rule-strong` | 14% / 30% 墨 | 16% / 32% 墨 |
| 强调（链接、焦点、滑块） | `--accent` | `#534ab7` | `#afa9ec` |

圆角只有三档：`--r-md` 8px（控件）、`--r-lg` 12px（卡片）、SVG 里 `rx="4"`。**单边边框不许加圆角**（`border-left` 配 `border-radius: 0`）。

## 三、分类色序（已通过校验，按顺序取用，不许循环）

| 槽位 | 令牌 | 400（数据色） | 亮色填充 / 文字 | 暗色填充 / 文字 |
|---|---|---|---|---|
| 1 | `--c1` 紫 | `#7f77dd` | `#eeedfe` / `#3c3489` | `#3c3489` / `#cecbf6` |
| 2 | `--c2` 青 | `#1d9e75` | `#e1f5ee` / `#085041` | `#085041` / `#9fe1cb` |
| 3 | `--c3` 珊瑚 | `#d85a30` | `#faece7` / `#712b13` | `#712b13` / `#f5c4b3` |
| 4 | `--c4` 蓝 | `#378add` | `#e6f1fb` / `#0c447c` | `#0c447c` / `#b5d4f4` |
| 5 | `--c5` 琥珀 | `#ba7517` | `#faeeda` / `#633806` | `#633806` / `#fac775` |
| 6 | `--c6` 品红 | `#d4537e` | `#fbeaf0` / `#72243e` | `#72243e` / `#f4c0d1` |
| 7 | `--c7` 绿 | `#639922` | `#eaf3de` / `#27500a` | `#27500a` / `#c0dd97` |
| — | `--c0` 灰 | `#888780` | 中性/结构节点专用，**不占分类槽位** | |
| — | `--c-warn` 红 | `#e24b4a` | 只用于「错误 / 发散 / 越界」这类状态 | |

**这 7 个槽位的顺序是跑出来的，不是挑出来的。** 亮暗两种模式下：

```
node scripts/validate_palette.js "#7f77dd,#1d9e75,#d85a30,#378add,#ba7517,#d4537e,#639922" --mode light
node scripts/validate_palette.js "#7f77dd,#1d9e75,#d85a30,#378add,#ba7517,#d4537e,#639922" --mode dark
→ 两次均 ALL CHECKS PASS（亮度带 / 彩度下限 / 相邻色盲 ΔE / 常色觉 ΔE / 对比度）
```

已知的失败边界，别踩：

- **加灰色当第 8 槽会 FAIL** —— `#888780` 彩度 0.01 低于下限，且与绿色的常色觉 ΔE 只有 14.8（<15）。灰是结构色，不是分类色。
- **用 600 档深色做数据色会 FAIL** —— 青 600 彩度不足读作灰，品红 600 与琥珀 600 的常色觉 ΔE 只有 12.5。数据色一律取 400 档。

改动任何一个颜色，**必须重跑校验器**，不要靠眼睛判断色盲安全性。校验器脚本在 `scripts/validate_palette.js`，来自 dataviz 技能，无依赖，`node` 直接跑。

## 四、颜色按「职责」分配，不按序号

| 数据的职责 | 用什么 | 规则 |
|---|---|---|
| **身份**（哪个类别） | `--c1..--c7` 按固定顺序 | 同一实体在整页保持同色；筛选后剩下的系列不许重新着色 |
| **量级**（大小、密度） | 单一色相由浅到深 | 取同一组色阶的 50→900，绝不用彩虹 |
| **极性**（正负、高低于基准） | 两个色相 + 中性灰中点 | 中点必须是灰，不能是第三种色相 |
| **状态**（对/错/警告） | `--c2` 成功、`--c5` 警告、`--c-warn` 错误 | 状态色是保留色，永远不能拿来当「第 4 个系列」；且必须配文字，不能只靠颜色 |

分类色最多用到 3 种。**颜色要编码含义，不要编码顺序**：同类节点同色（比如流程图里所有"输入"用青、所有"计算"用紫、所有"输出"用珊瑚），而不是第一步蓝、第二步黄、第三步红。

## 五、彩色底上的文字

底色用 `--cN-fill`，文字就必须用同一组的 `--cN-ink`，**永远不要在彩色底上用 `--ink-1` 或黑色**。一个框里同时有标题和副标题时，两者必须用不同深度：标题 `--cN-ink`，副标题 `--cN-ink2`；同一档读起来是平的，光靠字重拉不开。

## 六、物理写实场景（唯一允许写死颜色的地方）

画天空、水、火焰、金属、生物组织这类**真实物体**时，全部用写死的 hex，且不要跟 `c-*` 主题类混用——混用的结果是一半跟着暗色模式反转、一半不反转。需要暗色变体就显式写 `@media (prefers-color-scheme: dark)`。体检器会对写死颜色报 WARN，这种情况在交付说明里注明「物理写实场景」即可。
