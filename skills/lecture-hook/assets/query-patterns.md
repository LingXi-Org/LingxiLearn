# Query Patterns

Replace `[topic]` and add field-specific context.

- `[topic] history origin why developed`
- `[topic] invention discovery dispute priority`
- `[topic] famous failure accident case study`
- `[topic] surprising counterintuitive example`
- `[topic] misconception common mistake`
- `[topic] real world application engineering`
- `[topic] original paper archive`
- `[topic] university museum history`
- `[topic] controversy myth fact check`
- `[topic] before it existed problem`

For names or anecdotes discovered in secondary search, run a second query that targets the claimed event directly and prefers primary/academic sources.
